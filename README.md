# Modern CRM Application

A professional React Native application built with modern standards, featuring a scalable architecture and offline-first capabilities.

## 🚀 Features

- **Scalable Architecture**: Feature-based folder structure for better maintainability.
- **State Management**: Fully implemented with **Redux Toolkit** and **Redux Saga** for asynchronous side effects.
- **Local Persistence**: Data is persisted locally using **AsyncStorage**, allowing for offline usage.
- **Push Notifications**: Integrated local notification scheduling.
- **TypeScript**: 100% type-safe codebase for robust development.
- **Premium UI**: Clean, modern interface with custom components and smooth navigation.

## 📁 Project Structure

- `src/features`: Business logic separated by feature (Customers, Init).
- `src/screens`: UI screens including Welcome, Regions, and Customer management.
- `src/navigation`: App navigation stack configuration.
- `src/store`: Centralized Redux store with Sagas integration.
- `src/utilities`: Helper functions for Storage and Notifications.
- `src/components`: Reusable UI components.

## 🛠️ Technology Stack

- **React Native** (Expo SDK 55)
- **TypeScript**
- **Redux Toolkit** & **Redux Saga**
- **React Navigation**
- **AsyncStorage**
- **Expo Notifications**

## 🏁 Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npx expo start
   ```
